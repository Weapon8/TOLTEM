# TolTem — Calculateurs

Calculateurs tôlerie autonomes (HTML), hébergés via GitHub Pages.

- **[Trop-Plein](https://weapon8.github.io/TOLTEM/trop-plein.html)** — développé à plat (U, capot, pente, bec)
- **[EP / Fourreaux](https://weapon8.github.io/TOLTEM/ep-fourreaux.html)** — zinc/galva et fourreaux (table + formule)
- **[Boîte à eaux (BAE)](https://weapon8.github.io/TOLTEM/bae.html)** — corps, trop-plein, EP (position perso), sortie arrière · vue 3D + développé
- **[Fourreau 1.5](https://weapon8.github.io/TOLTEM/fourreau.html)** — fourreau carré/rectangle · 4 pièces (haut/bas/gauche/droite), pli platine, angles de pliage · vue 3D + développé
- **[Aide-mémoire](https://weapon8.github.io/TOLTEM/aide-memoire.html)** — les feuilles volantes de l'atelier au propre : garde de grève, oméga, solin, rive alu, colliers chapeaux (Ø300 à Ø600) · convertisseur de pente ° / % sur une largeur ou un diamètre
